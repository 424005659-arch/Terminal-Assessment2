NextPlay Hoops
- A responsive basketball training landing page built using Bootstrap 5, HTML, CSS, and JavaScript.
- This project was created as a Midterm Terminal Assessment focused on responsive web design, Bootstrap components, JavaScript validation, and UI/UX principles.

Features
* Responsive landing page design
* Bootstrap 5 Navbar
* Smooth scrolling navigation
* Hero section with basketball background
* Programs section with training cards
* Trainers section with coach profiles
* Contact form with JavaScript validation
* Book Training Modal
* Mobile-friendly layout
* Interactive hover effects

Technologies Used
* HTML5
* CSS3
* Bootstrap 5
* JavaScript
